---
name: Generated image dimensions
description: Image-generation aspect ratio is not guaranteed by descriptive prompting
---

Check generated image dimensions before making aspect-ratio assumptions.

**Why:** A panoramic service-delivery hero prompt returned a square image. Describing a ratio in the prompt did not guarantee that output ratio.

**How to apply:** Inspect the result before preparing banners. Preserve equipment and people without stretching; a quiet negative-space edge can be extended for copy placement when appropriate. Compute intrinsic dimensions from the final processed image, and describe generated workshop imagery as illustrative rather than actual company premises.
