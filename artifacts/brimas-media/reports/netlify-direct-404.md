# Direct error-document status correction

## Change

`netlify.toml` now has forced status-404 rules for `/404` and `/404.html`, before the unforced missing-page fallback. Each rule serves the other existing error-document path internally. These are custom-error responses, not HTTP 301/302 redirects, so there is no browser redirect chain.

The distinct targets avoid Netlify's ignored self-rewrite behavior. Both targets are generated by `scripts/prerender.mjs` and contain identical noindex error HTML. No prerender or design change was needed.

The `/api/*` function rewrite, unforced catch-all, build settings, Git remotes, and Replit artifact configuration are unchanged. Nothing was published.
